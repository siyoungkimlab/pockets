# Finding ligand pockets in apo structures

A static site (GitHub Pages) for apo/holo pairs: the apo and holo structures,
the sites Schrödinger MxMD + SiteMap finds, and the pockets CRUMB finds in
coarse-grained simulations of the apo protein (Martini 3, SIRAH, Martini 2),
each with the MD frame it was found in.

Drawn with `boonza view` (boonza.viewer.export): `viewer/` is the viewer's code,
shared by every pair; each pair's folder holds its page and `data/`.
